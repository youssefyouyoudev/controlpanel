# Action Catalog

The action catalog lives in `backend/config/youpanel-actions.php`.

Catalog definitions include:

- key
- name
- description
- category
- risk level
- required role
- confirmation requirements
- timeout
- executor
- fixed command array
- component types
- concurrency and backup hints

The browser cannot add commands, executables, working directories, arguments or process names. Disabled service actions document future intent and remain blocked.
